# Componentes de despliegue

No hay versiones de servicios seleccionadas ni infraestructura desplegada.

En B01/B02 registrar por componente: versión exacta, imagen/digest o release, licencia/edición, fecha de comprobación, enlace oficial, comando de validación y resultado. No sustituir estos datos por etiquetas `latest`.

Prototipo probado con Python 3.12; usa biblioteca estándar, compatible por diseño con Python 3.11+. CI propuesta: 3.11 y 3.12.
